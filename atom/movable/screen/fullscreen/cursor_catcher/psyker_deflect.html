psyker_deflect
/atom/movable/screen/fullscreen/cursor_catcher/psyker_deflect

Cursor tracker that also behaves like the normal click-catcher. The previous implementation, whilst it was more lightweight, had the issue in that it overrode regular click behaviour. We basically pass cursor movement directly along through signalers.

Procs

ClickRestores normal mouseclick functionality when using it, as cursor catchers normally just consume these clicks.
MouseMoveKeep the deflection target current without requiring a click or drag event.
calculate_paramsOverrides standard params behaviour so that we get the actual turf we hover over; this doesn't normally work on fullscreen cursor catchers.
