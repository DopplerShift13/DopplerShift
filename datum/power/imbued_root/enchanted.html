enchanted
/datum/power/imbued_root/enchanted

Vars

CDR_baseCDR = Cooldown Reduction. Is a gamer term. Flat deciseconds removed from qualifying cooldowns per second before power-based scaling.
CDR_cacheCached base cooldown recovery per second from the holder's current powers.
CDR_cache_dirtyWhether the cached cooldown recovery value needs to be rebuilt.
CDR_per_imbued_magic_valueAdditional deciseconds removed per point of Imbued magical power value.
CDR_per_magic_valueAdditional deciseconds removed per point of non-Imbued magical power value.

Procs

cache_CDR_per_secondCalculates our effective base cooldown recovery bonus and caches it for later procs.
get_CDR_per_secondCalculates the base cooldown recovery rate from the holder's magical powers. This defaults to using the cached value for optimization; and if its dirty/non-existant we cache a new vlaue.
get_recovery_multiplierHow much we multiply our recovery rate by after all enchanted rider powers contribute their additive percentages.
on_power_list_changedListens to changes in powers and marks the cache as dirty if the mob's powers are adjusted.
should_accelerate_actionProc that returns TRUE/FALSE if a power is qualified to get a CDR reduction from enchanted.
