riftwalker_red_rift_transit
/datum/riftwalker_red_rift_transit

Stores a single user's rift journey while using red rifts.

Vars

destination_riftRift the user will exit from
destination_turfTurf the user will exit from
initial_user_alphaUser alpha captured before the red rift fades them out.
origin_riftRift the mob enters from
origin_turfTurf the user started on
transit_startedHave we started teleporting?

Procs

apply_red_rift_tintApplies a dark-red tint, then starts its fade once the initial colour has reached the client.
apply_rift_instabilityHarms the user after entering another red rift shortly after entering another Mathematically, you're looking at about a 25% chance of receiving an injury that will kill you without immediate treatment.
